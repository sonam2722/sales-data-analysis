# Sales Data Analysis using Python + Power BI

##  Project Overview

This project analyzes sales data to understand sales performance, profit, quantity, products, and regional performance.

The analysis is performed using Python and the results can be visualized through charts and Power BI.

##  Problem Statement

Analyze sales, profit, quantity, products, and regional performance to identify important business trends and patterns.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Excel
- Power BI

## Analysis Performed

- Dataset preview and statistical analysis
- Top sales analysis
- Region-wise sales analysis
- Product-wise profit analysis
- Sales vs Profit relationship
- Quantity and sales data analysis

## Python Analysis

The Python script uses:

- **Pandas** for data loading and analysis
- **Matplotlib** for data visualization
- **Excel** as the source dataset
